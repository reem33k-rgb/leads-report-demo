# Leads report - demo

Live demo of an automated CRM leads report (exec summary, campaign / ad set / ad drill-down, Meta spend, cost per quote, old vs new campaigns, ad previews).
All numbers are generated demo data (`functions/_lib/fake.js`) - no real CRM or ad-account data.

- Live: https://leads-report-demo.pages.dev
- Case study PDF: https://leads-report-demo.pages.dev/case-study.pdf (source: `pdf/case-study.html`)
- Deploy: `npm run deploy` (Cloudflare Pages project `leads-report-demo`)
